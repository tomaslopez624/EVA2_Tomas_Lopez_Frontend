# Rediseño Frontend - Municipalidad de Cholchol 

Este proyecto consiste en el rediseño y reconstrucción de la página de inicio ("Home") de la **Municipalidad de Cholchol**. El objetivo principal es optimizar la experiencia de usuario, mejorar la imagen institucional y garantizar una navegación responsiva y accesible .

Desarrollado para la **Evaluación Sumativa Unidad 2** de la asignatura **Desarrollo Frontend** en el Instituto Profesional San Sebastián .

Tecnologías Utilizadas

* **React + Vite**: Entorno de desarrollo de alto rendimiento.
* 
**Tailwind CSS**: Framework de utilidades para un diseño moderno y responsivo.


* **PostCSS**: Procesamiento de estilos optimizado.
* 
**Git/GitHub**: Control de versiones y despliegue del código.


 Criterios de Evaluación Implementados

El proyecto cumple con los siguientes requerimientos técnicos solicitados en la pauta:

* 
**Interactividad Dinámica (CE1, CE3):** Implementación de eventos `onClick` y `onChange`, junto con la manipulación dinámica del DOM para la carga de noticias sin recargar la página.


* 
**Validación de Formularios (CE2):** Formulario de contacto con validaciones en tiempo real para Nombre, Email (formato RegEx) y Mensaje obligatorio .


* 
**Diseño Responsivo y Accesible (CE4):** Adaptación total para dispositivos móviles, tabletas y escritorio mediante Flexbox y Grid, utilizando etiquetas semánticas de HTML5 .


* 
**Principios de Diseño UI/UX (CE5, CE6):** Jerarquía tipográfica clara, paleta de colores institucional (azules/verdes) y organización de información coherente para mejorar la legibilidad .


* 
**Arquitectura de Componentes (CE7, CE8):** Organización profesional de carpetas en `src/layouts`, `src/components` y `src/assets`, siguiendo estándares de codificación modernos .



Instalación y Ejecución

Para correr este proyecto localmente, asegúrate de tener instalado **Node.js**.

1. **Clonar el repositorio:**
```bash
git clone https://github.com/TU_USUARIO/municholchol-frontend.git

```


2. **Entrar a la carpeta:**
```bash
cd municholchol-frontend

```


3. **Instalar dependencias:**
```bash
npm install

```


4. **Iniciar el servidor de desarrollo:**
```bash
npm run dev

```

Estructura del Proyecto

```text
src/
 ├── assets/      # Imágenes y recursos estáticos
 ├── components/  # Componentes reutilizables (Noticias, Contacto)
 ├── layouts/     # Estructuras globales (Navbar)
 ├── styles/      # Configuraciones de estilos
 ├── App.jsx      # Componente principal (Orquestador de secciones)
 └── main.jsx     # Punto de entrada de la aplicación

```
